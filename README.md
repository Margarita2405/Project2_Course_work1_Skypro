# Проект "Приложение для анализа банковских операций"

## Описание:

Данное приложение предназначено для анализа банковских транзакций из Excel-файла.
Оно предоставляет различные отчёты, сервисы и утилиты для работы с финансовыми данными,
включая расчёт кешбэка, формирование отчёта по категориям расходов, получение актуальных
курсов валют и цен акций, а также генерацию приветствий в зависимости от времени суток.

## Основные возможности:

* Загрузка и обработка данных из Excel-файла (формат .xlsx) с транзакциями.
* Главная страница (views) – формирует JSON-ответ с приветствием, данными по банковским картам 
  (последние 4 цифры карты, общая сумма расходов, кешбэк (1 рубль на каждые 100 рублей),
  топ-5 транзакциями, курсами валют и ценами акций за указанный период.
* Сервисы (services):
  Анализирует транзакции и рассчитывает кешбэк по категориям за месяц (1% от расходов).
* Отчёты (reports):
  Траты по заданной категории за последние три месяца (от указанной даты).
  Декоратор @report_decorator, автоматически сохраняет результат отчёта в JSON-файл 
  (с возможностью указать имя файла).
* Утилиты (utils):
  Приветствие в зависимости от времени суток.
  Загрузка транзакций из Excel.
  Фильтрация транзакций по дате.
  Обработка данных по картам (последние 4 цифры, сумма расходов, кешбэк).
  Получение топ-N транзакций по сумме платежа.
  Запрос курсов валют через API (exchangerates).
  Запрос цен акций через API (Twelve Data).
  Загрузка пользовательских настроек (валюты и акции для отображения) из JSON-файла.
* Логирование всех ключевых действий для отладки и мониторинга.
* Тестирование с использованием pytest и покрытием кода (цель > 80%).

## Установка и настройка:

1. Клонирование репозитория:
```
git clone https://github.com/Margarita2405/Project2_Course_work1_Skypro
```
2. Установка зависимостей:
```
pip install -r requirements.txt
poetry add requests
poetry add pandas
poetry add openpyxl
```
3. НАСТРОЙКИ API ДЛЯ КОНВЕРТАЦИИ ВАЛЮТ И ПОЛУЧЕНИЯ ЦЕН НА АКЦИИ.
Создайте файл .env в корне проекта и укажите API-ключи.
API-ключ для Exchange Rates Data API:
```
Зарегистрируйтесь на https://apilayer.com/marketplace/exchangerates_data-api
и получите бесплатный ключ
API_KEY=your_actual_api_key_here
```
API-ключ для TWELVE_DATA:
```
Зарегистрируйтесь на https://api.twelvedata.com/price и получите бесплатный ключ
API_KEY=your_actual_api_key_here
```

4. Пользовательские настройки (опционально)

Создайте файл data/user_settings.json со структурой:

{
    "user_currencies": ["USD", "EUR"],
    "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
Если файл отсутствует или имеет неверный формат, используются настройки по умолчанию.

5. Подготовка данных

Поместите файл с транзакциями operations.xlsx в папку data/. Ожидаемая структура файла
(лист "Отчет по операциям") содержит столбцы:

· Дата операции – в формате DD.MM.YYYY HH:MM:SS
. Номер карты (последние 4 цифры)
· Сумма операции (отрицательные значения – расходы)
. Валюта операции
· Категория
· Описание
· MCC

python src/main.py
Скрипт последовательно:

· Вызывает main_view для заданной даты и выводит результат в формате JSON.
· Загружает транзакции, рассчитывает кешбэк за декабрь 2021.

· Сохраняет отчёт в файл supermarkets.json с помощью декоратора.

# Подготовка к тестированию

Для запуска тестов необходимо выполнить следующие действия:

1. Установка зависимостей:
    ```
    pip install -r requirements.txt
    poetry add --group dev pytest
    poetry add --group dev pytest-cov
    poetry add requests
    ```
# Запуск тестов

1. Для запуска всех тестов используйте следующую команду в 
терминале: 
    ```
    pytest tests
    ```
2. Запуск тестов из конкретного файла:
    ```
    pytest tests/test_reports.py
    pytest tests/test_services.py
    pytest tests/test_utils.py
    pytest tests/test_views.py
    ```
3. Ожидаемый результат.
После успешного выполнения тестов вы должны увидеть вывод, 
подтверждающий, что все тесты успешно пройдены, например:
    ```
    === 10 passed in 0.01s ===
    ```
4. Если тесты не прошли.
Проверьте вывод команды на наличие ошибок.
Обратитесь к файлам тестов для анализа причин сбоев. 

5. Для запуска тестов с оценкой покрытия, используйте следующую
команду в терминале: 
    ```
    pytest --cov=src
    ```
6. Для создания отчета о покрытии в HTML-формате, используйте 
следующую команду в терминале: 
    ```
    pytest --cov=src --cov-report=html
    ```
## Логирование

Все ключевые действия логируются с использованием стандартного модуля logging.
Уровень логирования можно изменить в файлах модулей (по умолчанию DEBUG). Логи выводятся
в консоль и могут быть перенаправлены в файл при необходимости.

### Настройка
Чтобы изменить поведение логирования (например, отключить перезапись), 
отредактируйте настройки в файле reports.py, utils.py, services.py, views.py.
